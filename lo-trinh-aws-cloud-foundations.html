Lộ trình học AWS

Cloud Foundations trong 4 tuần

Lộ trình theo 11 module của khóa AWS Academy Cloud Foundations, chuẩn bị cho chứng chỉ Cloud Practitioner. Khoảng 5–6 giờ mỗi tuần. Tick từng mục khi xong, tiến độ được lưu ngay trong trình duyệt của bạn.

Cách học cho nhớ lâu

  • Mỗi module: xem bài giảng, làm Knowledge Check, làm lab. Đừng bỏ lab.
  • Cuối mỗi module, viết 5 dòng tóm tắt bằng lời của bạn.
  • Lập bảng so sánh các dịch vụ dễ nhầm: S3 / EBS / EFS, EC2 / Lambda / Beanstalk, RDS / DynamoDB.
  • Học xong buổi nào thì tắt hoặc xóa tài nguyên buổi đó để tránh phát sinh chi phí.
  • Trước khi đăng ký thi, đọc exam guide mới nhất của Cloud Practitioner trên trang AWS vì nội dung và mã đề có thể thay đổi.
Sau Cloud Practitioner: học tiếp Lambda, API Gateway, DynamoDB, CloudFormation và làm một dự án cuối, rồi hướng tới Solutions Architect – Associate.
